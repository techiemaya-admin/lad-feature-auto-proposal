## What to build

Advanced table loop synthesis and narrative scope container collapsing in `template-mutator.service.ts` that resolves the "Pruning vs. Synthesis" trap and preserves hybrid composite table structures.

`executeCollapseRepeatingTable()` is generalized to support mid-table sub-range collapsing. In hybrid tables like Fieldstone's `Your Investment` table, the function accepts an explicit `template_row_index` (Row 2 for add-ons), converts Row 2 into `{#addon_items}{addon_name} | {addon_fee}{/addon_items}`, prunes redundant sample add-on rows (Row 3) in reverse order, and leaves Row 1 (Base Project Build) and Rows 4–6 (Subtotal, Bundle Discount, Total) as fully intact data rows.

Inner cells of repeating loop rows are populated with dynamic column tags derived from `compoundTable.columns` (e.g. `{phase_number}`, `{milestone_title}`, `{deliverable_summary}` for milestones; `{addon_name}`, `{addon_fee}` for add-ons), eliminating hardcoded sample text inside loops.

Multi-bullet scope and SLA sections (such as Northstar's `Included vs. Not Included — Growth Tier` and Fortress IT's `04 What's Included This Cycle`) are collapsed as a single narrative container: `executeReplaceTextRun()` strips markdown bullet prefixes (`- `), injects `{scope_deliverables_summary}` into paragraph 1, and safely prunes redundant sibling bullet paragraphs (2..N) from the OpenXML AST up to the next heading or section boundary.

In `mutateDocumentTemplate()`, mutation operations are partitioned into deterministic phases:
1. Phase 1: Text run replacements
2. Phase 2: Scalar cell replacements and conditional row wrapping
3. Phase 3: Table loop collapsing (executed last to prevent row index shifting bugs)

Templates are hydrated and verified using `easy-template-x` across all 3 benchmark proposals (`Fieldstone`, `Fortress IT`, `Northstar`), asserting Markdown equivalence against the Expected Results in `Templatized Documents.md`.
