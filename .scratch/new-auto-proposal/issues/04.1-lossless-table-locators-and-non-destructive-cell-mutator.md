## What to build

A hardened, non-destructive table and text mutation engine in `template-mutator.service.ts` that prevents Row 0 column header overwrites, eliminates blind cell substitution fallthrough, and supports safe two-tier text run replacement.

`findTableAndRow()` is upgraded to incorporate semantic column header verification (matching column titles like `"Line Item | Amount"` or `"Date | Prepared By"`). It defaults `allowHeaderRow: false`, permanently protecting Row 0 from being targeted as a data row. When `row_identifier` is absent, it respects `template_row_index` (defaulting to Row 1, never Row 0).

`executeReplaceTableCell()` replaces the destructive Case B fallthrough with a strict match-or-fail contract: when `sample_text` is supplied, it must match within the targeted cell (or adjacent data cells in that specific row); if no match is found, the mutator leaves the cell text completely untouched, returns `{ applied: false }`, and logs an informative warning. Direct cell substitution (`table.setCell`) is strictly limited to cases where `sample_text` was omitted and Col 0 matched an exact `row_identifier`.

`executeReplaceTextRun()` is enhanced with two-tier replacement logic:
1. **High-Entropy Entities (`client_name`, `client_company_name`):** Replaced globally across all paragraphs in the document without stopping at the first match, ensuring both header titles and introductory narrative clauses are updated.
2. **Low-Entropy Terms (Enums like `selected_tier`, Numbers like `server_count`, and Currency):** Replaced using strict regex word boundaries (`\b`) and scoped to paragraphs matching `context_anchor`, preventing collateral corruption like `$7{server_count}.00`.

## Acceptance Criteria

- [x] `findTableAndRow()` defaults `allowHeaderRow: false` and verifies table headers semantically against candidate text.
- [x] Row 0 (column headers) in Table 0, Table 1, and Table 2 across all three proposals are 100% protected and cannot be overwritten by data tags or wrapped by conditional tags.
- [x] `executeReplaceTableCell()` never destroys cell text when `sample_text` is not found; blind fallthrough to `table.setCell()` is removed.
- [x] In Fortress IT (`co2_msp`), Table 1 Row 0 (`"Standard — Recommended"`) and Table 2 Row 0 Col 1 (`"42"`) remain intact and are not overwritten by mismatched valid-until dates or tiers.
- [x] `executeReplaceTextRun()` replaces `client_name` across all body paragraphs (e.g. in Fieldstone, replacing `"Rosewood Home Goods"` in both the title and the intro narrative).
- [x] Replacing numeric sample values (such as `"5"` for `server_count`) uses word-boundary matching (`\b5\b`), leaving surrounding prices like `"$75.00"` untouched.
- [x] Mutator unit and integration tests in `template-mutator.test.ts` pass cleanly with zero header overwrites.
